# Telegram 18+ Landing

Простой статический лендинг для перехода в Telegram.

## Что внутри

- `index.html` — структура страницы
- `styles.css` — стили
- `main.js` — ссылка на Telegram и базовая логика
- без backend
- без БД
- без токенов
- без API
